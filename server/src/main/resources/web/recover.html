새 휴대폰으로 기록 복구

휴대폰을 바꿨거나 잃어버렸다면, 등록해 둔 비상 연락처 한 사람의 승인으로 기록을 다시 열 수 있습니다.

비상 연락처에게 승인 요청 문자를 보냈습니다. 그분께 전화해서 아래 코드를 불러 주세요. 그분 화면의 코드와 같아야 승인됩니다.

승인되면 이 화면이 저절로 넘어갑니다.

복구되었습니다. 이 휴대폰에서 기록을 다시 볼 수 있습니다.

차량을 쓸 수 있다면, 주차한 상태에서 차량 화면의 휴대폰 탭 → 다른 휴대폰 연결로 이 휴대폰을 한 번 더 연결해 두세요. 앞으로 차량이 새 열쇠를 만들 때 이 휴대폰으로 바로 받게 됩니다.
