# White Box (화이트박스)

사고와 분쟁의 순간 운전자가 실제로 한 조작(브레이크·방향지시등·조향·기어·속도·위치)을 차량이 **위변조 불가능하게** 기록하는 Pleos Connect 앱입니다.
모든 기록은 SHA-256 해시 체인으로 연결되고, 급제동·충격이 감지되면 사고 전 최대 120초를 **기기 서명으로 봉인한 캡슐**로 남깁니다.
기록은 운전자 본인의 증거이며, 한 바이트만 바뀌어도 검증이 실패합니다.

> 2026 HMG App Dev Contest 출품작 · 패키지 `com.americankimchilabs.whitebox`

---

## 실행 방법

### 방법 1: APK 설치 (권장)

```bash
adb install -r apk/americankimchi_WhiteBox_release.apk
adb shell am start --user 10 -n com.americankimchilabs.whitebox/.MainActivity
```

디버그 빌드가 이미 설치되어 있으면 서명이 달라 `INSTALL_FAILED_UPDATE_INCOMPATIBLE`이 나므로 먼저 `adb uninstall com.americankimchilabs.whitebox`를 실행합니다.
앱 목록의 **화이트박스** 아이콘(한국어가 아닌 차에서는 White Box)으로 실행해도 됩니다. 첫 실행은 주차(P) 상태에서 권한 화면 하나(차량 속도, 위치, 위치 '항상 허용'을 이유와 함께 한 번에 안내; 허용하기를 누르면 시스템이 두 번 묻습니다) → 허용하지 않은 항목이 있으면 그때 안 되는 기능과 기록 보호 안내(차량 속도와 위치는 필수라 허용할 때까지 처음으로 돌아가고, '항상 허용'은 권장 — 없어도 기록은 시동과 함께 시작되고 앱을 열지 않은 주행에 사고 장소만 남지 않음) → 사고 감지 개선 참여 질문 → 무엇을 기록하고 어디에 보관하는지 보여 주는 준비 화면 순서입니다. 글자는 돋보기 없이 읽을 수 있게 차량 기본 크기보다 크게 썼고, 줄은 단어 사이에서만 바뀌며 문장마다 새 줄에서 시작합니다(휴대폰 화면도 같음). **대리 운전 모드** 버튼은 주차 중 상태 표시줄 오른쪽 끝에 있습니다.

### 방법 2: 소스 빌드

```bash
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

- JDK 17, Android SDK 35가 필요합니다. SDK 위치는 `ANDROID_HOME` 환경변수 또는 `local.properties`의 `sdk.dir`로 지정합니다.
- Pleos Vehicle SDK는 `https://nexus-playground.pleos.ai/repository/maven-releases/`에서 받으므로 네트워크가 필요합니다.
- 단위 테스트: `./gradlew test` (Kotlin 194개 — 기록으로 본 상황 문장(차와 휴대폰이 같은 문장인지 확인), 구간 시작 때 상태(한 번만, 구간 시작 기준으로, 암호화해 봉인), 시동 꺼짐 뒤 잠든 시간, 배포 설정(비밀값의 서버 키, 대시보드 비밀번호), 에스컬레이션 엔진과 위험 패턴(에어백이 충돌 캡슐을 큰 사고로 바꿈(보관함에서도 바로 큰 사고), 시험용 에어백), 요금제·보관(보관함 칸과 한 건 들어오면 한 건 나감, 위험 순간이 충돌보다 먼저 빠짐, 연장한 기록은 빠지지 않고 칸이 모두 연장 기록이면 새 기록이 빠짐, 빠진 기록은 30일 보관 뒤 업그레이드로 복귀, 연장, 다운그레이드 유예, 클라우드 보관 기간, 차의 저장 정리와 체크포인트, 압축 파일 분할·복구, 속도 저장 간격과 급발진·추돌 보존, 증거 파일 검증, 차량 영상 첨부), 대리 운전 모드(출발 전 켜기·늦게 도착한 휴대폰 요청·잠시 정차 후 재출발·재시작·단속 카메라와 구간 단속·급가속·경로 이탈·휴대폰 명령 재전송), 음성 보관 확인·인식 문구·동기화 신호, 클라우드 미러(송신 정책·서버 수신·변조 거부·데드맨), 기록 암호화·분 단위 열쇠·사고 열쇠 위탁·열쇠 교체·휴대폰 연결·소유자 변경·비상 연락처·데이터 동의, 주행 목록, 도로 경사 추정, 증거 요약 타임라인, 해시 체인 내구성·변조 속성 테스트, 데모 주행 엔드투엔드 재생). 이어서 휴대폰 화면의 JavaScript 테스트 19개가, 차량 코드가 만든 기록·타임라인·서명·동기화 신호와 구간 시작 때 상태를 똑같이 풀고 그리는지, 전체 화면 그래프가 영상 구간에 맞는지, 차가 말하는 모든 안내 문장을 상세 기록에 그대로 옮기는지 확인합니다(Node.js 18 이상이 있으면 자동 실행, 없으면 건너뜀).
- 릴리스 빌드는 `local.properties`의 서명 정보를 읽습니다(`app/build.gradle.kts` 주석 참고). 서명 정보가 없으면 서명되지 않은 릴리스가 만들어지고 디버그 빌드에는 영향이 없습니다.

## 운영 서버 (Cloud Run 서울)

제출 APK는 설치하면 바로 운영 서버 `wss://whitebox-920773743992.asia-northeast3.run.app/v1/stream`에 연결해 기록 사본을 보냅니다(서버가 닿지 않으면 차에 쌓아 두었다가 이어서 보냄). 서버는 Google Cloud Run(서울)에서 돌고, 기록은 Firestore, 저장한 블랙박스 영상은 Cloud Storage에 둡니다.

- **대시보드 열기**: 인증번호(시연용 문자)와 요금제 전환이 있는 화면입니다.
  1. 브라우저에서 https://whitebox-920773743992.asia-northeast3.run.app 을 엽니다.
  2. 브라우저가 띄우는 로그인 창의 **사용자 이름**에는 아무 글자나(예: `judge`) 넣습니다. 확인하지 않는 칸입니다.
  3. **비밀번호**에는 제출 메일에 적은 **대시보드 비밀번호**를 넣습니다.

  아래 경로처럼 이 컴퓨터에서 실행한 서버(`http://localhost:8080`)의 대시보드는 비밀번호 없이 바로 열립니다.
- **휴대폰**: 보안 연결(https)이라 실제 휴대폰으로 차 화면의 QR을 찍어 연결하고, 증거 요약 QR도 휴대폰 카메라로 열 수 있습니다.
- 아래 로컬 실행 경로는 그대로 쓸 수 있습니다(테스트 빌드나 `--es mirror local`은 이 컴퓨터의 서버로 연결).

## 클라우드 미러 대시보드 직접 확인하기 (심사위원용)

차량이 보낸 기록을 받는 서버(`:server`)를 심사위원의 컴퓨터에서 실행하고, 브라우저 대시보드에서 직접 확인할 수 있습니다. **JDK 17**만 있으면 됩니다(`java -version`으로 확인). 경로 A는 Android SDK나 에뮬레이터가 필요 없습니다.

### 경로 A: 에뮬레이터 없이 (약 3분)

1. **터미널 1**에서 서버를 켭니다. 처음에는 의존성 내려받기로 1–2분 걸릴 수 있습니다.
   ```bash
   ./gradlew :server:run
   ```
   `White Box mirror on :8080`이 보이면 준비된 것입니다.
2. 브라우저에서 **http://localhost:8080** 을 엽니다(1초마다 갱신, 펼쳐 둔 '자세히'는 그대로 유지).
3. **터미널 2**에서 모의 차량을 실행합니다. 차량 앱과 같은 기록·전송 코드로 데모 주행(차선 변경, 급제동, 충돌)을 실시간으로 보냅니다.
   ```bash
   ./gradlew :server:demoCar
   ```
4. 대시보드에서 다음 순서로 바뀌는 것을 확인합니다.

   | 시점 | 대시보드 |
   |---|---|
   | 시작 | `데모 차량` 카드가 생기고 '주행 중'. 10초마다 '받은 기록'이 늘어남 |
   | 약 52초 | `급제동 감지` → `충격 감지 · 기록 보관`. 차량 봉인이 다른 기록보다 먼저 도착함. 충돌 직후 에어백 전개 신호가 오면서 같은 기록이 **큰 사고**가 되고, 그 구간의 열쇠가 함께 와서 '비상 연락처 열람 가능'이 붙음 |
   | 약 53초 | 모의 차량이 **전원 손실**처럼 전송을 멈춤 |
   | +10초 | **서버 봉인**: 서버가 받은 기록 범위에 직접 서명 |
   | +60초 | **충격 뒤 연결 끊김**: 충돌 뒤에도 차에서 신호가 없어 '충격 뒤 연결 끊김 (서버 봉인)'이 **큰 사고**로 보관 기록에 추가됨(에어백 신호를 보내지 못한 차라도 10년 보관, 비상 연락처 열람 가능). 누구에게도 문자를 보내지 않음 |

   기술 정보(기기 ID, 기록 번호, 봉인 서명, 경과 기록)는 카드의 **자세히**에 있습니다.

5. 비교용으로, 정상 종료하는 주행에서는 서버 봉인이 생기지 않습니다(정차 후 '정상 (경보 해제)').
   ```bash
   ./gradlew :server:demoCar --args="--drive-on"
   ```

실행할 때마다 새 차량(새 키)으로 카드가 하나씩 추가됩니다. 서버가 받은 내용은 `server-data/streams/<기기 ID>/<replay|live>/`에 남습니다: `records.log`(받은 기록), `seals.log`(차량 봉인), `anchors.log`(서버가 서명한 체인 끝), `attested.log`(서버 봉인), `severe-silent.log`(충격 뒤 연결 끊김), `escrow.log`(큰 사고의 분 단위 열쇠, 서버 키로 봉인), `opened.log`(가족 열람 기록). 처음 상태로 돌리려면 서버를 끄고 `server-data/`를 지웁니다.

### 경로 A-2: 휴대폰 화면 — 증거 요약, 블랙박스 동기화, 비상 연락처 (에뮬레이터 없이, 약 5분)

기록의 값(속도, 브레이크, 위치 등)은 차량에서 암호화된 채로 서버에 올라가며, **평소 주행과 위치는 차주의 휴대폰만** 풀 수 있습니다. 서버도 가족도 열 수 없습니다. 에어백이 터진 큰 사고가 봉인될 때만 차량이 그 몇 분의 열쇠를 서버에 맡겨, 등록된 비상 연락처가 그 사고 기록을 열 수 있게 합니다. 실제로 문자는 보내지 않고 인증번호는 대시보드 위쪽 **문자 (시연용)** 칸에 나타납니다. 번호는 아무 010 번호나 쓰면 됩니다.

1. 서버를 켠 상태에서(경로 A의 1–2단계) 모의 차량을 "휴대폰 연결" 모드로 실행합니다.
   ```bash
   ./gradlew :server:demoCar --args="--phone"
   ```
   터미널에 `http://localhost:8080/claim#…` 주소가 나옵니다. 실제 차량에서는 이 주소가 차량 화면의 QR 코드입니다.
2. **차주**: 그 주소를 브라우저로 열고, 휴대폰 번호 → 인증번호(대시보드에 표시) → **연결하기** → **내 차 보기**. 모의 차량이 주행하는 동안 마지막 위치와 속도가 이 브라우저에서 풀려 나타납니다.
3. **비상 연락처**: 같은 화면의 "연락처 추가"에 이름과 다른 번호를 넣습니다. 병원 서류의 비상 연락처처럼 상대에게 묻거나 문자를 보내지 않습니다.
4. **증거 요약**: 주행 시작 약 52초에 충돌이 일어나면 '보관 기록'에 **충격 감지**가 나타납니다. 누르면 시각·위치·속도 변화에 이어 **기록으로 본 상황**이 먼저 나옵니다: 기록된 값만으로 쓴 문장과 그 뜻("앞 유리 와이퍼가 감지 전 4분 동안 작동 → 비나 눈이 오고 있었을 가능성이 높습니다"). 그 아래에 감지 직전 운전자의 조작, 속도·조향·브레이크·방향지시등·기어를 한 시간축에 겹친 그래프가 있고, 맨 아래 접힌 **상세 기록**에 그때의 차량 상태와 차가 기록한 모든 값이 있습니다. 차는 값이 바뀔 때만 기록하므로, 구간이 시작되기 오래전에 정해진 상태(안전벨트, 문, 전조등, 기어, 신호 대기 중 계속 밟은 브레이크 등)는 기록을 봉인할 때 '구간 시작 때 상태'로 함께 담습니다. 그래서 차량 상태가 비지 않고, 그래프도 처음부터 이어지며, "브레이크는 감지 2분 전에 이미 밟고 있었고"처럼 읽힙니다. 차 화면에서는 보관 기록마다 종류별 색 카드와 **증거 요약 보기 ›** 버튼이 있고(돌아갈 때는 큰 **← 이전**), 증거 요약은 시각, 감지 내용, 속도("시속 56 km → 30 km (0.3초 만에 26 km 줄어듦)" 또는 "감지 순간 시속 25 km (10초 전 시속 60 km)"), 감지 순간 조작, 보관한 구간("감지 53초 전부터 12초 뒤까지")과 가장 중요한 세 문장, QR을 보여 주고, 기록 번호·봉인 시각·체인 해시·기기 서명 키는 **자세히 보기**에 접어 두고, 위치는 차 화면에 보이지 않습니다("차주 휴대폰에서만 볼 수 있습니다"). **원본 그대로입니다 · 변조 없음**은 이 브라우저가 해시 체인, 차량 서명, 서버 서명을 직접 확인한 결과입니다(근거는 '자세히'). **인쇄**하면 한 장짜리 증거 요약이 됩니다.
5. **블랙박스 영상과 맞춰 보기**: 모의 차량은 실제 차처럼 몇 초마다 들리지 않는 동기화 신호(20–22 kHz)를 내고 그 시각을 기록합니다. 주행이 끝나면 터미널에 그 소리를 녹음한 블랙박스 대용 파일(`…/20261101_000054.wav`처럼 블랙박스 시계로 이름이 붙고, 그 시계는 일부러 2.7초 빠름)의 경로가 나옵니다. 그 파일을 고르면 **동기화 신호로 정확히 맞췄습니다**가 뜨고, 영상(여기서는 소리) 아래에 그래프가 편집 프로그램처럼 쌓여 하나의 재생 위치로 움직입니다. 그래프를 누르거나 끌면 영상이 그 순간으로 갑니다. **전체 화면**을 누르면 영상이 위, 그 영상 구간만의 그래프가 아래로 화면을 채우고, 보라색 재생선이 영상과 함께 움직이고 멈춥니다(휴대폰에서는 브라우저의 전체 화면, **← 돌아가기**로 원래 화면). 실제 블랙박스 영상(MP4)도 같은 방법으로 고릅니다. **이 영상 저장하기**를 누를 때만 영상이 이 휴대폰에서 암호화되어 올라가며(서버는 내용을 볼 수 없음), 다시 열면 맞춘 위치 그대로 열립니다. 그 기록을 열 수 있는 사람(큰 사고라면 비상 연락처, 공유 링크를 받은 사람)도 영상을 볼 수 있습니다.
6. **비상 연락처(가족)**: 다른 브라우저(또는 주소를 `http://127.0.0.1:8080/contact`로 바꿔 쿠키가 따로인 탭)에서 `/contact`를 열고 3단계에서 넣은 번호로 인증합니다. **큰 사고 기록만** 보입니다. 에어백이 터진 큰 사고는 서버가 건넨 그 몇 분의 열쇠로, 신호가 끊긴 사고는 서버가 받은 사고 신호 사본으로 열립니다. 평소 주행·위치 요청은 거절됩니다. 차주 화면에는 "○○ 님이 사고 기록을 열어 봤습니다"가 남습니다.
7. **주행 기록**: 차주 화면의 **주행 기록 모두 보기**에서 날짜별 주행과 거리·위험 순간을 보고, 주행을 누르면 속도 그래프가 열립니다.
8. **증거 요약 QR (보험사·경찰용)**: 모의 차량은 끝날 때 충돌 기록의 QR 주소(`http://localhost:8080/capsule#…&t=…&k=…`)를 터미널에 보여 줍니다. 실제 차량에서는 증거 요약 화면 오른쪽 위의 QR입니다. 로그인하지 않은 브라우저(예: `localhost`를 `127.0.0.1`로 바꾼 주소)에서 열면 그 기록 하나만 열리고 원본 검증까지 됩니다. 기록을 여는 열쇠는 주소의 `#` 뒤에만 있어 서버로 가지 않고, 서버는 공유 코드의 해시만 압니다. 차주 화면에는 "증거 요약 QR로 누군가 열어 봤습니다"가 남습니다. QR은 90일 동안 유효합니다.

알아 두면 좋은 동작:
- **다시 인증**: 오래 지나 로그인이 풀리면 번호와 인증번호만 다시 넣으면 됩니다(QR 불필요). 열쇠는 브라우저에 그대로 있습니다. 서버를 다시 켜도 로그인은 유지됩니다.
- **휴대폰을 바꾸면** 같은 번호로 차량 QR을 다시 찍으면 됩니다. 차량이 지금까지의 열쇠를 모두 새 휴대폰에 봉인해 줍니다. 차와 휴대폰을 함께 잃어도 큰 사고 기록은 서버에 맡긴 열쇠로 남습니다.
- **다른 번호가 차량 QR로 연결을 요청하면**(차를 판 경우) 지금 차주에게 문자와 승인·거절 카드가 갑니다. 승인하면 바로, 거절하지 않으면 3일 뒤 넘어갑니다. 요청이 오는 순간 차는 아무도 열 수 없는 새 키로 기록을 시작해, 기다리는 동안의 기록도 빠짐없이 남습니다. 넘어가면 새 소유자가 요청한 때부터의 기록을 보고, 거절되면 그 기록은 기존 소유자가 봅니다. 이전 소유자는 자기 기록을 계속 볼 수 있고, 판 뒤의 차량 상황은 보이지 않습니다.
- **사고 데이터 제공 동의**: 차량 앱을 처음 열면(주차 상태) 한 번만, 왜 필요한지와 보내는 것·보내지 않는 것을 먼저 보여 주고 묻습니다. 기본은 '보내지 않음'이고, 휴대폰 탭에서 언제든 바꿀 수 있으며 그만두면 보낸 자료도 삭제됩니다.
- **누구에게도 자동으로 문자를 보내지 않습니다**: 비상 연락처를 저장할 때도, 사고가 감지되어도 마찬가지입니다(감지가 틀릴 수도 있는데 가족을 놀라게 하지 않기 위해서입니다). 가족은 필요할 때 직접 들어와 봅니다.

에뮬레이터에서는 주차(P) 상태의 앱 화면 **휴대폰** 탭 → **휴대폰 연결**을 누르면 QR과 같은 주소가 표시되며, 그 주소를 이 컴퓨터의 브라우저로 열면 됩니다(경로 B의 3단계 이후).

### 경로 A-3: 대리 운전 모드 (에뮬레이터 없이, 약 3분)

대리기사님에게 차를 맡기는 동안의 운전을 기록하고, 끝나면 리포트를 남깁니다.

1. 서버를 켠 상태에서 경로 A-2의 1–2단계처럼 휴대폰을 연결하되, 모의 차량을 대리 운전 모드로 실행합니다.
   ```bash
   ./gradlew :server:demoCar --args="--phone --handover"
   ```
2. 차주 화면의 **대리 운전** 카드가 "대기 중" → "운전 중"으로 바뀝니다. 터미널에는 차가 기사님께 하는 말이 나옵니다. 출발하면 "대리 운전 모드입니다. 주행이 기록됩니다.", 단속 카메라(제한 40 km/h)를 60 km/h로 지나면 "속도를 줄여 주세요.", 급제동하면 "안전 운전 부탁드립니다."라고 합니다.
3. 주행이 끝나면 차는 주차하고 시동을 끕니다. 실제 차는 10분 뒤에 리포트를 확정하고(그 사이 다시 출발하면 같은 운행으로 이어짐), 시연에서는 20초 뒤에 확정합니다. 터미널에 리포트 QR 주소가 나오고, 차주 화면의 **보관 기록**에도 **대리 운전 리포트**가 생깁니다.
4. 리포트에는 운전 시간, 거리, 최고 속도, 켠 곳과 끝난 이유, 기록된 운전과 시각, 속도 그래프가 있습니다. 차주는 **공유 링크 만들기**로 대리운전 업체에 보낼 주소를 만들 수 있고, 로그인하지 않은 브라우저에서 열면 그 리포트 하나만 열리며 원본 검증까지 됩니다.

실제 차에서 켜고 끄는 방법:
- **켜기**: 차주 휴대폰의 **대리 운전 모드 켜기**(출발 전이면 언제든, 조수석에서 기사님을 기다리며 켜도 됨), 또는 주차 중 차 화면의 **대리 운전 모드 → 켜기**. 차가 P를 벗어나는 순간 운전이 시작되고, 휴대폰 요청이 출발 직후에 도착해도 출발 시점부터 기록합니다. 12시간 안에 출발하지 않으면 저절로 꺼집니다.
- **목적지**: 목적지 없이 출발하면 "목적지를 설정해 주세요."라고 말하고 차가 서 있을 때 내비게이션을 띄웁니다. 목적지가 있으면 경로 이탈("경로를 확인해 주세요.")과 도착도 기록됩니다.
- **끝**: 시동을 끄거나, 목적지 도착 직후 주차하거나, 시동을 켠 채 10분 넘게 주차하면 마무리에 들어가 10분 뒤 확정됩니다. 차주는 휴대폰에서 언제든 끝낼 수 있습니다. 운전 중에는 차 화면에서 끌 수 없고, 휴대폰 연결 QR과 기록 출처 전환도 숨겨집니다.
- **과속**: 한국 도로에서 의미 있는 것만 기록합니다. 단속 카메라를 지날 때 제한속도보다 10 km/h 넘게 빠르거나, 구간 단속 평균이 그렇게 높을 때입니다. 급가속은 1초에 11 km/h 이상(5 km/h 이상에서 출발한 경우), 급제동·급핸들·충격은 사고 감지 엔진과 같은 기준입니다. 같은 안내는 1분에 한 번만 합니다.
- 대리 운전 리포트는 데이터 제공 동의와 상관없이 서버의 학습 자료로 쓰지 않습니다.

### 경로 A-4: 요금제와 보관 (에뮬레이터 없이, 약 3분)

대회 시연은 **프로 요금제**로 모든 기능을 보여 줍니다(서버의 기본값). 결제는 연동하지 않았고, 결제 자리는 "시연용 결제: 실제로 돈이 나가지 않습니다."라고 표시한 대체 구현이 맡습니다.

| | 무료 | 플러스 | 프로 |
|---|---|---|---|
| 큰 사고(에어백 전개) 기록 | 10년 무료 | 10년 무료 | 10년 무료 |
| 주행 기록 보관(클라우드) | 7일 | 14일 | 30일 |
| 보관함(위험 순간 + 대리 운전 리포트) | 3개 | 12개 | 120개 |
| 블랙박스 영상 저장 | 2개 | 4개 | 10개 |
| 대리 운전 모드 | – | ✓ | ✓ |
| 보험·경찰 제출용 사고 경위서 | – | – | ✓ |

1. 경로 A-2로 휴대폰을 연결하고 주행을 마칩니다. 차주 화면 아래 **프로 요금제** 카드에 보관 기간, 쓰고 있는 칸, 세 요금제가 나옵니다.
2. 보관 기록을 열면 **보관** 카드에 삭제 예정일(사고 시점부터 30일)과 **1년 연장 · 9,900원**, **3년 연장 · 19,900원**, **증거 파일 내려받기 (무료)**가 있습니다. 연장은 무료 30일이 끝나는 날부터 더해집니다. 연장한 기록도 칸을 차지합니다. 연장한 기록은 결제한 기간까지 빠지지 않습니다. 보관함이 가득 차면 연장하지 않은 오래된 위험 순간부터 빠지고(그다음이 충돌), 모든 칸이 연장한 기록이면 새로 생긴 기록이 빠집니다. 빠진 기록은 사고 시점부터 30일까지 서버에 남아 있다가 그 안에 업그레이드하면 다시 돌아옵니다. 운전자가 "아니"라고 답한 기록은 연장하면 보관함에 들어오지만, 보관함이 가득 찬 동안에는 연장할 수 없습니다. 삭제 7일 전에는 차주 화면 위쪽에 안내가 뜹니다.
3. 증거 파일은 기록, 봉인, 서버 서명, 그 기록의 열쇠를 담은 텍스트 파일입니다. White Box 없이 검증하려면:
   ```bash
   tools/tamper-demo/run.sh ~/Downloads/whitebox-<기록 번호>.txt
   ```
4. **보험·경찰 제출용 사고 경위서**(프로): 기록을 해석한 문장(예: "와이퍼가 감지 전 4분 동안 작동 … 비가 왔을 가능성이 높습니다", 근거와 함께), 감지 직전 조작과 그래프, 신뢰성 확인, 당사자 기재란, 맨 아래 상세 기록 전체가 인쇄용 한 문서로 나옵니다. 해석은 규칙으로만 만들며 기록에 없는 내용은 쓰지 않습니다.
5. 제한을 보려면 대시보드(`http://localhost:8080`)의 차 카드에서 **요금제 (관리자 전환)**를 **무료**로 바꿉니다. 차주 화면의 대리 운전 카드가 "플러스 요금제부터"로 바뀌고, 영상을 세 개째 저장하면 "이전 영상을 지우고 저장" / "플러스로 업그레이드" / "프로로 업그레이드"가 나옵니다(연장한 영상은 바꾸지 않습니다). 차주 화면의 요금제 카드에서 업그레이드를 누르면 시연용 결제로 바로 바뀝니다. 서버 전체의 기본값은 `WHITEBOX_DEFAULT_TIER=FREE ./gradlew :server:run`처럼 바꿀 수 있습니다.

### 경로 B: Pleos 에뮬레이터 + 제출 APK

1. 경로 A의 1–2단계로 서버와 대시보드를 켭니다.
2. 위의 [실행 방법](#실행-방법)대로 APK를 설치하고 첫 실행(권한)을 마칩니다.
3. 앱이 이 컴퓨터의 서버로 보내도록 바꿉니다. 에뮬레이터는 호스트 컴퓨터를 `10.0.2.2`로 보며, 앱은 이 주소에만 TLS 없는 연결을 허용합니다.
   ```bash
   adb shell am start --user 10 -n com.americankimchilabs.whitebox/.MainActivity --es mirror local
   ```
   몇 초 안에 `실시간 차량` 카드가 생기고, 그동안 차에 쌓인 기록을 이어서 받습니다.
4. Virtual Console로 주행합니다. 먼저 아래 [B. 실시간](#b-실시간-virtual-console)의 준비 두 줄(`adb forward`, `heartbeat.sh`)을 실행한 뒤, 충돌 직후 앱을 멈춰 전원 손실을 흉내 내려면:
   ```bash
   python3 tools/virtual-console/demo.py --power-loss
   ```
   경로 A와 같이 `충격 감지 · 기록 보관` → 10초 뒤 서버 봉인 → 60초 뒤 '충격 뒤 연결 끊김'이 나타납니다. 다만 에뮬레이터에는 에어백 신호가 없어 차의 기록은 **충돌**로 남고, 신호가 끊긴 뒤 서버가 봉인한 기록이 **큰 사고**가 됩니다. 이어서 다른 패턴은 `patterns.py`로 확인할 수 있습니다(앱을 다시 열면 기록이 재개되고, 그 공백도 체인에 남습니다).
5. 원래 설정으로 되돌리기: `--es mirror default`.
6. 요금제: 서버에 연결된 차는 차주의 요금제를 서버에서 받습니다(대시보드에서 전환). 서버 없이 쓰는 차는 기본이 프로이며, 테스트 빌드에서는 `--es tier FREE`(또는 `PLUS`, `PRO`)로 바꿔 볼 수 있습니다(제출 APK에는 없음). 무료에서 위험 순간이 네 번째로 보관되면 가장 오래된 기록이 보관함에서 빠지고, 보관 기록 탭에 안내가 뜨며, 주차하면 "보관함이 가득 차 오래된 기록을 정리했습니다."라고 말합니다. 빠진 기록은 사고 시점부터 30일까지 서버가 보관해 두며, 그 안에 업그레이드하면 자리가 있는 만큼 다시 돌아옵니다.

## 데모

### A. 데모 재생 (테스트 빌드 전용, 녹화용)

꾸며 낸 주행은 제출 APK에 들어 있지 않습니다. 제출 APK는 차가 알려 주는 신호만 기록합니다. 데모 재생은 테스트 빌드(`./gradlew :app:installDebug`)에서만 쓸 수 있습니다. 앱 하단 **데모 재생** 버튼, 또는:

```bash
adb shell am start --user 10 -n com.americankimchilabs.whitebox/.MainActivity --es source REPLAY
```

약 70초짜리 주행이 재생됩니다: 출발 → 좌측 차선 변경(방향지시등) → 일반 제동 → 우측 차선 변경 → **급제동(경보)** → **충돌 프로파일 50→25 km/h (충격 감지·봉인)** → **에어백 전개 신호(큰 사고)** → 정차 10초 후 최종 봉인. 재생 기록은 실차 기록과 별도의 체인에 저장됩니다.

### B. 실시간 (Virtual Console)

같은 시나리오를 에뮬레이터의 Virtual Console HTTP API로 실제 차량 신호 경로(VHAL → SDK → 앱)를 통해 주입합니다.

```bash
adb forward tcp:18088 tcp:8088
tools/virtual-console/heartbeat.sh &        # 콘솔 세션 유지 (콘솔 페이지를 열어둔 것과 동일)
adb shell am start --user 10 -n com.americankimchilabs.whitebox/.MainActivity --es source LIVE
python3 tools/virtual-console/demo.py
```

감지 패턴을 하나씩 확인하려면(급핸들, 급제동하며 급핸들, 주행 중 기어 중립(N), 브레이크를 밟았는데 속도 증가, 브레이크를 여러 번 밟음, 급출발, 후방 추돌, 급제동 후 문 열림) 같은 준비 상태에서 다음을 실행합니다. 시나리오마다 체인에 기록된 감지 결과를 기대값과 나란히 출력합니다.

```bash
python3 tools/virtual-console/patterns.py              # 전체 (약 5분)
python3 tools/virtual-console/patterns.py evasive lurch # 일부만
```

대리 운전 모드를 실제 신호 경로로 확인하려면, 같은 준비 상태에서 차 화면이나 휴대폰에서 대리 운전 모드를 켜고 다음을 실행합니다. 출발, 급가속(1초에 +15 km/h), 급제동, 주차까지 운전한 뒤 차가 체인에 남긴 대리 운전 기록을 출력합니다. 에뮬레이터의 시동은 밖에서 끌 수 없으므로, 리포트는 휴대폰의 **지금 끝내기**로 확정하거나 10분간 주차해 두면 확정됩니다.

```bash
python3 tools/virtual-console/handover.py
```

### C. 음성

에뮬레이터 마이크는 호스트(Mac) 마이크입니다: `adb emu avd hostmicon`. 앱은 마이크 권한이 필요 없습니다(녹음은 차량 음성 서비스 안에서 이루어짐).

- **보관 확인**: 위험 패턴 뒤 5초가 지나도 계속 주행 중이면(`patterns.py evasive`) 차량이 "방금 상황 보관할까요?"라고 묻습니다. 질문이 끝난 뒤 **10초** 동안 답을 듣습니다. "아니"·"취소"는 보관함에서 내리고("보관 취소"), "응"·"보관해" 또는 무응답은 보관합니다("보관 완료"). 답은 캡슐의 라벨로 체인에 남고, 운전자가 한 말 자체는 기록하지 않습니다.
- **끼어들기**: 전화나 Gleo 등 다른 앱이 오디오를 가져가면 질문·듣기를 멈추고, 끝난 뒤 질문은 다시 하고 듣기는 10초를 새로 줍니다. 에뮬레이터에서는 `adb emu gsm call 5551234` / `adb emu gsm cancel 5551234`로 확인할 수 있습니다.
- **음성 북마크(통신 가능 시)**: "글레오" → "화이트박스에서 방금 상황 저장해 줘". Gleo Interface(`assets/schema.json`의 `BOOKMARK_MOMENT`)로 직전 120초가 캡슐로 봉인되고 Gleo가 결과를 말합니다.
- **음성 북마크(통신 불가 시)**: Gleo는 통신 없이는 동작하지 않으므로, 그때만 White Box가 Pleos SpeechToText 온디바이스 인식으로 "방금 저장해"를 직접 듣습니다(`adb shell cmd connectivity airplane-mode enable`로 확인). 통신이 돌아오면 마이크를 닫습니다. 주의: 이 에뮬레이터는 비행기 모드를 켜면 차량 신호(Virtual Console → VHAL)도 끊기고, 끈 뒤에도 네트워크가 돌아오지 않아 재부팅해야 합니다. 그래서 시연 영상의 주행 장면에는 이 기능을 넣지 않았습니다.
- **사고 직후 안내**: 충돌 수준 감지 뒤 기어를 P로 바꾸면 "사고 기록 완료. 과실 인정은 피하고, 현장을 촬영하세요."라고 한 번 안내합니다(`demo.py` 끝부분).
- **블랙박스 동기화 신호**: P가 아닐 때 15초마다 사람이 들을 수 없는 20–22 kHz 신호를 내보내고, 실제 재생 시각(첫 프레임)을 체인에 남깁니다.

### D. 클라우드 미러와 데드맨 스위치

로컬 체인이 원본이고, 서버는 사본을 받습니다. 서버는 이 저장소의 `:server`(Kotlin, Ktor)이며, 직접 실행해 보는 방법은 위의 [대시보드 직접 확인하기](#클라우드-미러-대시보드-직접-확인하기-심사위원용)에 있습니다.

- **상시 연결**: 차량은 WebSocket 하나를 항상 열어 둡니다(15초 핑). 사고 순간에 새로 연결하느라 시간을 쓰지 않습니다. 연결할 때마다 기기 키로 서버의 챌린지에 서명해 자기 기기임을 증명하고, 기기 ID는 그 키에서 나오므로 다른 차의 기록에 쓸 수 없습니다.
- **평상시**: 10초마다 마지막으로 확인받은 기록 이후를 묶어 보냅니다. 묶음은 WebSocket 압축(permessage-deflate)으로 절반 이하가 됩니다(암호화된 값은 줄지 않고 해시·시각·구조가 줄어듦, 실제 기록으로 측정 45%). 사고 순간의 작은 프레임은 압축 없이 바로 보냅니다. 서버는 기록마다 해시와 앞뒤 연결을 확인한 뒤 저장하고(기기·순번 기준 중복 무시, 다른 내용이 오면 거부하고 기록), 받은 체인 끝을 서버 키로 서명해 둡니다. 터널 등으로 끊기면 차에 쌓였다가 다시 연결되면 이어서 보냅니다.
- **급제동·충격 감지 시**: 브레이크·속도·조향·기어와 단계 변화 기록을 생기는 즉시 두 번씩, 응답을 기다리지 않고 보냅니다. 봉인은 무엇보다 먼저 보냅니다. 정상으로 돌아온 기록이 서버에 '해제' 신호가 됩니다.
- **데드맨 스위치**: 위험 신호 뒤 해제 신호 없이 차에서 10초간 신호가 없으면, 서버가 받은 범위에 직접 서명해 봉인합니다. 60초가 지나고 충돌 수준의 증거(차가 보낸 충격 감지, 또는 받은 속도 기록을 같은 감지 엔진으로 다시 돌린 결과)가 있으면 그 서버 봉인을 '충격 뒤 연결 끊김'으로 가족 화면에 올려 둡니다. 문자는 보내지 않습니다. 이 기록은 차가 서버에 보낸 사고 신호 사본(속도·브레이크·조향·기어, 위치 제외)으로 보여 줍니다.

### E. 변조 검증

```bash
tools/tamper-demo/run.sh
```

에뮬레이터에서 실제로 기록된 체인(`docs/artifacts/live-run2-demo`)을 앱과 같은 검증 코드로 확인합니다: 원본은 **PASS**, 속도 값 1바이트를 바꾼 사본은 해당 레코드에서 **FAIL**, 이후 해시를 모두 다시 계산한 위조본도 서명된 봉인과 헤드가 달라 **FAIL**.

휴대폰에서 내려받은 증거 파일도 같은 도구로 확인합니다(`tools/tamper-demo/run.sh whitebox-<기록 번호>.txt`): 해시·연결, 차량 봉인 서명, 서버 서명을 다시 계산하고, 파일 안의 열쇠로 값을 열어 보여 줍니다.

### F. 시연 시나리오와 블랙박스 영상

시연 영상의 장면을 Virtual Console로 그대로 재현하는 스크립트와, 그 주행에 맞춘 블랙박스 영상을 만드는 도구입니다. 블랙박스 영상은 같은 종류의 순간을 실제로 찍은 블랙박스 영상(위키미디어 공용, 공개 저작물: 사람이 아닌 자동 장치가 찍은 영상)을 쓰고, 그 주행 동안 차가 낸 동기화 신호음과 실내 소음을 소리에 넣어 블랙박스가 녹음한 것처럼 만듭니다. 차의 신호(속도, 브레이크, 조향)는 영상 속 상황에 맞춰 스크립트로 넣습니다. 영상은 저장소에 넣지 않고 처음 한 번 내려받으며, 원본 블랙박스의 날짜·기기 번호 줄은 시연 시각과 어긋나지 않게 잘라 냅니다. 맞는 실제 영상이 없는 장면(주차장 급출발, 야간 대리 운전)은 엉뚱한 영상을 붙이지 않고 영상 없이 보여 줍니다.

```bash
python3 -I tools/virtual-console/dashcam.py fetch          # 실제 블랙박스 영상 3개 내려받아 준비 (약 15 MB, 한 번만)
python3 -I tools/virtual-console/scenarios.py cut-in       # 주행 (B의 준비 두 줄, 앱은 --es mirror local)
python3 -I tools/virtual-console/dashcam.py make cut-in --data server-data
```

| 시나리오 | 장면 | 기록 | 블랙박스 영상 |
|---|---|---|---|
| `cut-in` | 고가도로 아래 도심 도로, 옆 차가 앞으로 끼어들어 브레이크 후 접촉 | 충돌, 증거 요약에 "시속 29 km → 8 km", "브레이크는 감지 1.3초 전에 밟았고", P에서 사고 직후 안내 | 실제 접촉 사고 (14초) |
| `pile-up` | 고속도로 시속 100 km, 앞의 연쇄 추돌을 급제동으로 피하고 계속 주행 | 위험 순간, 5초 뒤 "방금 상황 보관할까요?" | 실제 연쇄 추돌 현장 회피 (22초) |
| `garage` | 주차장에서 멈췄다가 급출발 (급발진 패턴) | 급출발 | 없음 |
| `rear-end` | 고속도로 시속 108 km, 차로의 느린 화물차, 충돌 전 브레이크 없음, 전원 끊김 | 충돌 → (테스트 빌드) 시험용 에어백 신호로 큰 사고 → 서버 봉인, 비상 연락처 열람 | 실제 고속도로 추돌 (22초) |
| `night` | 대리 운전 모드로 야간 주행, 앞을 가로지른 차에 급제동 | 대리 운전 리포트, "안전 운전 부탁드립니다." | 없음 |

영상마다 보여 줄 만한 구간(`watch`: 사건 약 2초 전부터 더 새로운 장면이 없는 곳까지)이 정해져 있어 시연에서는 그 부분만 재생합니다. `make`는 서버가 받은 기록에서 그 시나리오의 감지 시각과 차가 신호음을 낸 시각을 읽어, 영상 속 사건(접촉, 급제동, 충돌)이 감지 시각에 오도록 영상을 놓고, 영상 구간에 든 신호음을 소리에 넣습니다. 파일 이름(`REC_날짜_시각`)과 헤더에도 시작 시각을 적습니다. 휴대폰의 기록 화면 **블랙박스 영상과 맞춰 보기**에서 이 파일을 고르면 "동기화 신호음으로 정확히 맞췄습니다 (오차 약 0.001초)"가 나옵니다(세 시나리오 모두 에뮬레이터에서 확인). 신호음은 15초마다 반복되므로, 파일의 시각이 7초 안으로 맞을 때만 신호음으로 확정합니다. 다른 기록의 영상을 고르면 "파일 이름의 시각이 이 기록과 맞지 않습니다"라고 알리고 정확히 맞췄다고 하지 않습니다. 소리는 압축하지 않은 PCM으로 넣습니다(AAC는 20 kHz 이상을 잘라 신호음이 사라짐). 영상 준비와 만들기에는 macOS(AVFoundation) 또는 ffmpeg가 필요합니다.

## 에뮬레이터 한계 (정직하게)

- **에어백 신호 없음**: v2.1.0 이미지의 VHAL에는 `SEAT_AIRBAGS_DEPLOYED` 속성이 없고(SDK 호출은 `ERROR_NOT_SUPPORTED_PROPERTY`), Virtual Console에도 에어백 카드가 없습니다. 큰 사고(10년 무료 보관, 비상 연락처 열람)는 에어백이 터진 사고만이라 에뮬레이터에서는 저절로 생기지 않습니다. 충돌 수준의 속도 변화는 **충돌**로 감지·봉인됩니다. 큰 사고를 보려면 **테스트 빌드**(`./gradlew :app:installDebug`)에서 아래처럼 시험용 에어백 신호를 넣습니다. 이 기록은 차·휴대폰·대시보드·증거 파일 어디서나 "시험용 에어백 신호"로 표시됩니다. 제출 APK(릴리스)에는 이 기능이 아예 들어 있지 않습니다.
  ```bash
  adb shell am start --user 10 -n com.americankimchilabs.whitebox/.MainActivity --ez test_airbag true
  ```
- **ABS 경고등은 읽을 수 없음**: 경고등 조회는 실행 시 `PRIVATE_CAR_SAFETY` 권한을 요구합니다(인터페이스 문서의 `CAR_SAFETY`와 다름). 그래서 트리거에 쓰지 않습니다.
- **콘솔 페달만으로는 충격 감지가 되지 않음**: 콘솔의 제동 물리 모델은 최대 42 km/h/s(약 1.2 g)로, 실제 최대 제동과 같은 수준이라 일부러 사고 기준(16 km/h/300 ms)에 못 미칩니다. 시연 스크립트는 콘솔 API로 속도 급감을 직접 주입합니다. 콘솔의 `speed` 값은 **정수 km/h**만 받습니다.
- **설치 직후 재부팅은 70초 이상 기다릴 것**: 설치 직후의 앱은 'stopped' 상태라 부팅 브로드캐스트를 받지 못하고, 첫 실행으로 풀린 상태가 저장되기까지 시간이 걸립니다(7.8초 뒤 재부팅 시 재현, 70초 뒤에는 정상). '강제 종료'한 경우에도 앱을 다시 열 때까지 자동 시작되지 않으며, 그 공백은 다음 기록 시작 시 체인에 남습니다.
- **Suspend(시동 끔)**: 실차는 시동을 끄면 저전력 Suspend 모드로 들어가 앱이 멈춥니다. 앱은 시동이 꺼지는 순간(IGNITION OFF) 음성 질문·듣기를 멈추고 오디오를 돌려주며, 깨어난 뒤 다시 묻지 않습니다. 깨어나면 잠들어 있던 시간을 체인에 "시동이 꺼져 차가 잠들어 있던 N분 · 그동안 기록 없음"으로 남깁니다. 에뮬레이터의 `cmd car_service suspend --simulate`는 앱을 멈추지 않는 모의 동작이라(확인함) 이 기록은 생기지 않고, 콘솔로는 시동 상태를 바꿀 수 없어 시동 꺼짐 동작도 에뮬레이터에서는 볼 수 없습니다(실차 경로, 단위 테스트로 확인).
- **앱 마켓 링크**: 새 버전 안내의 "앱 마켓 열기"는 `market://detail?package=…`를 엽니다. 에뮬레이터에는 앱 마켓이 없어 열리지 않고(안내가 닫힘), 실차에서는 Pleos 앱 마켓이 엽니다.
- **차량 속도 권한의 '다시 묻지 않음'**: Android는 두 번째 권한 창부터 '허용하지 않고 다시 묻지 않음'을 보여 줍니다. 차량 속도에서 이것을 고르면 v2.1.0 이미지의 설정 어디에도 다시 켜는 항목이 없습니다. 그래서 두 번째 창 위에 빨간 경고를 띄우고, 막힌 경우 그 사실을 그대로 알립니다(Pleos에 문의 예정).
- 시스템 권한 창의 문구는 에뮬레이터 언어 설정을 따릅니다(영어 설정에서는 'Allow all the time' = '항상 허용').
- **도로 경사는 실차에서만**: 헤드유닛 가속도계로 도로 경사를 계산하지만(장착 방향은 주행 중 속도 변화로 자동 학습, 양산 헤드유닛의 가속도계 탑재 여부는 Pleos 확인 필요), 에뮬레이터의 가속도계는 Virtual Console 주행과 무관한 고정값이라 경사가 기록되지 않습니다. 그래서 내리막 제동과 구분해야 하는 '브레이크를 밟는데 감속 없음' 패턴은 에뮬레이터에서 동작하지 않고, 급발진 시연은 경사와 무관한 '브레이크를 3초 이상 밟은 채 속도 상승'(3초에 12 km/h 이상, 매초 상승)으로 합니다.
- **내비게이션 도로 정보**: 에뮬레이터의 내비게이션 위치는 콘솔 주행을 따라가지 않아 제한속도가 항상 0이고 주의 구간·단속 카메라 안내가 나오지 않습니다. 앱은 변화를 기록하고, 내리막 주의 구간에서는 감속 없음 패턴을 끄도록 구현되어 있습니다.
- **대리 운전 모드의 과속·경로 이탈**: 위와 같은 이유로 에뮬레이터에서는 단속 카메라 안내와 경로 재탐색이 나오지 않아, 단속 카메라 과속과 경로 이탈은 모의 차량(경로 A-3)에서만 보입니다. 에뮬레이터에서는 급가속·급제동, 휴대폰에서 켜고 끄기, 리포트와 공유 링크까지 확인했습니다. 시동 꺼짐으로 끝나는 흐름도 같은 이유로 모의 차량에서 확인하며, 실제 차가 시동을 끌 때 잠드는(Suspend) 동작에서의 확인은 실차가 필요합니다.
- **EV 순간 효율**: 이 이미지는 지원하지 않아 구독하지 않습니다. 지원 차량에서는 값만 기록하고 해석하지 않습니다(단위 미확인).
- **CCP(로터리) 입력**: 에뮬레이터의 로터리 서비스는 주입한 회전 입력을 앱 화면으로 전달하지 못합니다(기본 주행 화면에서도 포커스 이동 실패). 앱은 모든 버튼·목록·증거 요약 블록이 포커스를 받고 포커스 테두리를 표시하도록 구현했으며, 방향키 입력으로 포커스 이동·선택·뒤로가기를 확인했습니다. 실제 CCP 하드웨어 동작은 실차에서 확인이 필요합니다.
- **휴대폰 쪽 화면**: 키를 만드는 브라우저 기능(WebCrypto)은 보안 연결(https)이나 같은 컴퓨터의 `localhost`에서만 동작합니다. 그래서 로컬 서버로 볼 때는 이 컴퓨터의 브라우저가 휴대폰 역할을 하고, 실제 휴대폰은 운영 서버(https)로 연결합니다. 인증번호·문자는 발송 대신 대시보드에 표시합니다(실제 발송 채널은 인터페이스만 갖춤).
- **클라우드 서버**: 제출 APK는 운영 서버(Cloud Run 서울, TLS)에 연결합니다. 로컬 서버는 `--es mirror local`로 지정하며, 앱은 에뮬레이터 호스트 주소 `10.0.2.2`에만 TLS 없는 연결을 허용합니다. 운영 서버는 인스턴스 하나로 돌고(데드맨 타이머가 한곳에서 돌도록), 요청이 없으면 꺼졌다가 첫 연결 때 몇 초 안에 다시 켜집니다.
- **내장 카메라 영상 자동 첨부**: Pleos는 앱에 카메라 접근을 열어 두지 않았습니다. 차가 영상을 받아 암호화·서명해 올리는 부분(카메라 포트, 업로드, 서버의 서명 확인)은 구현·테스트되어 있고, 카메라 접근이 열리면 플러스·프로에서 켜집니다. 지금은 휴대폰에서 고른 블랙박스 영상만 저장합니다.
- **결제**: 실제 결제는 연동하지 않았습니다. 요금제 변경과 기록 연장은 결제 포트의 시연용 구현으로 즉시 반영되고, 화면에 "시연용 결제"라고 표시합니다.
- **바퀴 회전 신호(`WHEEL_TICK`)**는 고정된 자리값만 나와 사용하지 않습니다.
- **Gleo 연동 승인**: 에뮬레이터에서는 승인 전 스키마로도 Gleo 호출이 동작합니다. 실차에서는 Pleos가 스키마를 승인해야 활성화됩니다. Gleo는 앱이 보낸 결과 문구를 자기 말로 바꿔 말합니다.
- **음성 인식 정확도**: 에뮬레이터에서는 Mac 합성 음성(Yuna)을 스피커로 재생해 확인했습니다. 실제 목소리와 차량 실내 소음에서의 정확도는 실차 확인이 필요합니다. 인식은 Pleos 하이브리드 모드로, 앱 등록이 열리면 서버 인식이 코드 변경 없이 켜지고 지금은 온디바이스로 동작합니다.
- **동기화 신호 대역**: 20–22 kHz는 사람이 듣지 못하는 대역입니다. 다만 에뮬레이터의 소리 출력은 이 신호를 16–17 kHz로 낮춰 내보내(측정함) 많은 사람에게 들리고, 시연 영상에도 그대로 들립니다. 앱은 출시 빌드와 테스트 빌드 모두 20–22 kHz로 내며, 48 kHz로 소리를 내는 실제 헤드유닛에서는 들리지 않을 것으로 봅니다(실차 확인 필요). 시판 블랙박스 중 그 대역을 녹음하지 않는 기종은 영상 파일의 시각(블랙박스 시계)으로 맞추고, 시계가 기록과 맞지 않으면 직접 맞추도록 안내합니다.
- **주행 중 주차 브레이크**: 콘솔의 주차 브레이크는 경고등만 켤 뿐 `PARKING_BRAKE_ON` 속성은 계속 false라(확인함) 이 패턴은 에뮬레이터에서 시연할 수 없습니다. 감지 코드는 실차용으로 남아 있습니다.
- 조향각 부호: SDK는 콘솔 각도를 반대 부호로 전달하며, 공식 문서에 부호 규약이 없어 증거 요약은 좌/우 표기 없이 부호 있는 각도로만 표시합니다.

## 기록과 무결성

- **열쇠 교체(epoch)**: 차를 다른 사람이 연결하면 차량은 그 순간부터 새 열쇠로 기록합니다. 새 차주는 이전 차주의 기록을 열 수 없습니다. 같은 차주의 새 휴대폰은 자기 열쇠를 모두 받습니다.
- **분 단위 열쇠와 사고 열쇠 위탁**: 기록은 1분마다 루트 키에서 따로 만든 열쇠(HKDF-SHA256)로 암호화됩니다. 에어백이 터진 큰 사고가 봉인될 때마다 차량은 그 사고가 걸친 몇 분의 열쇠만 서버 키로 봉인해 보냅니다. 에어백 없는 충돌 수준의 충격(충돌)은 사고 대응(즉시 봉인·우선 전송·서버 봉인)은 같지만 보관은 위험 순간과 같고(30일, 칸 사용) 차주만 봅니다. 충돌 뒤 차 신호가 끊겨 서버가 봉인한 기록은 큰 사고로 다룹니다. 서버는 차주이나 등록된 비상 연락처가 번호 인증을 마쳤을 때만 그 열쇠를 건네고, 가족이 열람할 때마다 차주 화면에 남깁니다. 다른 시간의 기록은 이 열쇠로 열리지 않습니다(테스트로 확인). **위치**는 분마다 따로 만든 위치 열쇠로 암호화됩니다: 차 화면에는 나오지 않고, 차의 증거 요약 QR(분 열쇠만 담음)로도 열리지 않습니다. 위치 열쇠는 차주 휴대폰이 루트 키로 만들고, 차주가 휴대폰에서 만든 공유 링크와 큰 사고 때 비상 연락처에게 맡기는 열쇠에만 함께 들어갑니다(테스트로 확인).
- **값은 암호화, 형태는 공개**: 기록의 값(속도, 브레이크, 조향, 위치 등)은 체인에 들어가기 전에 차량의 루트 키(AES-256-GCM)로 암호화됩니다. 기록의 종류와 시각, 경보·봉인 표시는 그대로 두어 서버도 해시·연결·시각을 검증할 수 있지만 내용은 읽을 수 없고, 차량의 파일도 저장 상태에서 암호화됩니다. 루트 키는 차량에서 만들어 Android Keystore 키로 감싸 보관하고, 차주 휴대폰에는 그 휴대폰 브라우저가 만든 키로만 열리게 봉인해 전달합니다(P-256 ECDH + HKDF-SHA256 + AES-GCM, 브라우저 WebCrypto와 같은 방식).
- **서버가 읽을 수 있는 것은 사고 신호뿐**: 경보 중의 핵심 신호(브레이크·속도·조향·기어)는 데드맨 스위치가 충돌 신호를 판단할 수 있도록 서버 키로 봉인한 사본을 함께 보냅니다(안전 기능). 캡슐이 닫히면 그 구간의 신호(위치 제외)와 운전자의 응답을 기기와 분리된 가명으로 서버 키로 봉인해 보내는데, 이것은 **운전자가 동의한 경우에만** 보내며 동의를 거두면 삭제합니다. 서버는 받은 것을 자체 키로 다시 암호화해 보관합니다.
- **전화번호와 남용 방지**: 전화번호는 서버에 암호화해 두고, 찾을 때는 서버 비밀키로 만든 해시를 씁니다. 인증번호 문자는 번호당 30초, 접속 주소당 10분에 20건, 전체 분당 60건으로 제한합니다.
- **휴대폰 연결은 차량 화면을 본 휴대폰만**: QR 주소의 # 뒤에는 차량만 아는 비밀값이 있어 서버로 전송되지 않습니다. 휴대폰은 이 값으로 자기 키에 서명(HMAC)하고, 차량은 그 서명을 확인한 뒤에만 루트 키를 봉인해 줍니다. 서버가 자기 키를 끼워 넣어도 서명을 만들 수 없습니다.
- **휴대폰에서 직접 검증**: 증거 요약 화면은 받은 기록의 해시와 연결, 차량의 봉인 서명(ECDSA), 서버가 서명한 체인 끝을 브라우저에서 직접 확인합니다. 이 JavaScript는 차량 코드가 만든 기록·타임라인·서명으로 자동 테스트됩니다(`server/src/test/web`).
- **추가 전용 체인**: 이벤트마다 한 줄, 쓰기마다 fsync. 각 줄은 이전 줄의 SHA-256 해시를 포함합니다. 쓰는 도중 프로세스가 죽으면 마지막 미완성 줄만 버려집니다(테스트로 검증).
- **차에는 필요한 만큼만**: 클라우드가 보관소이고, 차는 클라우드가 받았다고 확인한 기록 3일, 아직 올리지 못한 기록(최대 14일, 넘으면 지운 사실을 체인에 남김), 보관함의 기록만 남깁니다. 서버 없이 쓰는 차는 7일을 남깁니다. 기록 파일은 1만 건마다 닫아 압축하므로 앱은 열린 파일 하나만 메모리에 색인합니다. 지운 구간의 마지막 해시는 체크포인트로 남아 남은 기록이 그대로 이어지고, 보관함 기록은 따로 남아 검증됩니다. 에뮬레이터에서 잰 기록량은 시간당 약 10 MB였고 그중 88%가 초당 10번 오는 속도였습니다.
- **속도는 바뀔 때마다**: 감지 엔진은 모든 원본을 보지만, 평소 주행에서 값이 그대로인 속도는 1초에 한 번만 저장합니다. 값이 바뀐 순간, 바뀌기 직전의 마지막 같은 값, 급제동·충격 감지 중의 모든 값은 그대로 저장하므로 급발진(브레이크를 밟은 채 속도 상승)이나 전조 없는 추돌의 기록은 줄지 않습니다(테스트로 확인).
- **클라우드 보관 기간**: 요금제의 기간이 지난 주행 기록은 서버에서 지우고, 보관함·연장·큰 사고 기록의 구간은 남깁니다. 지운 구간은 "보관 기간이 지나 정리됨"으로 계산되어 차의 전송은 그대로 이어집니다.
- **캡슐 봉인**: 충격 감지 즉시 임시 봉인(전 120초 포함), 정차 10초 뒤 최종 봉인. 봉인은 Android Keystore의 ECDSA P-256 키로 서명합니다.
- **기록 공백도 기록**: 서비스 재시작(재시도 횟수 포함), 권한 저하·복구, 강제 종료 후 복구가 체인에 남아 타임라인에서 "기록하지 못한 시간"이 보입니다.
- 실제 기록 체인: [`docs/artifacts/`](docs/artifacts/README.md)
